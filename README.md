# E-Learning Management System

## Project Description
This is an E-Learning Management System developed using PHP, MySQL, HTML and CSS.

## Features
- Student Registration and Login
- Student Dashboard
- Course Management
- Lessons and Study Materials
- Online Quizzes
- Quiz Results
- Student Profile
- Admin Login
- Admin Dashboard
- Manage Courses
- Manage Students
- View Quiz Results

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP
- VS Code

## Database
Database Name: e_learning

## Project Purpose
The system provides an online platform where students can access courses, study lessons, take quizzes and view their results.
